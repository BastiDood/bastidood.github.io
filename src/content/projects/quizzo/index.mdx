[Quizzo](https://github.com/BastiDood/quizzo) is a [Tokio](https://tokio.rs/)-powered [Discord bot](https://discord.com/api/oauth2/authorize?client_id=823813267133956136&scope=applications.commands) written in [Rust](https://www.rust-lang.org/) for hosting limited-time quizzes. With Discord's built-in [message components](https://discord.com/developers/docs/interactions/message-components#message-components), Quizzo provides an easy-to-use interface (and a trivially scalable setup) for large-scale quizzes with many users. When the quiz timer expires, Quizzo notifies everyone in the channel which users answered the quiz correctly. The pioneer use of message components differentiates Chrozone from the other bots in the market which use clunky reaction-based polling mechanisms.
