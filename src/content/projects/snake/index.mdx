Using the popular [<dfn><abbr title="Simple DirectMedia Layer 2.0">SDL2</abbr></dfn>](https://www.libsdl.org/) library, the [`sdl-basic-snake`](https://github.com/BastiDood/sdl-basic-snake) project reimplements the classic game [Snake](<https://en.wikipedia.org/wiki/Snake_(video_game_genre)>) with modern object-oriented C++20 code.

In line with the theme of modern best practices, the project also uses [CMake](https://cmake.org/) as its cross-platform build system generator. Assuming the necessary system dependencies have been set up, the project may be built and run on any platform.
