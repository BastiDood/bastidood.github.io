# BastiDood's Personal Website

This Astro codebase features a statically generated website that contains the blog posts and personal portfolio of Basti Ortiz ("BastiDood").

## Typical Workflow

After implementing a feature, fixing a bug, refactoring modules, or any other notable change to the codebase:

1. Run the linter `pnpm lint:fix`.
2. Run the formatter `pnpm fmt:fix`.
